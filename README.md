# Gigachat Assistant
Hello! This is my small and humble project about the Gigachat neural network. This project features code that has been integrated into a Telegram bot. This project is aimed at a beginner audience and is not a professional project.

What you need to do to make the code work:

First, you need to follow this link: https://developers.sber.ru/portal/gigachat-and-api

Register, then use the instructions to get your Access token. After that, paste it into config.py -> access_token = ""

Next, enter your bot_token in config.py -> Test_Python = " "

After completing all of this, everything will work for you!

I remind you that this is a test project and it is not official.
